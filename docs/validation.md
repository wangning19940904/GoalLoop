## 一周加速时间线与真实时长分开记录

测试 `runs an accelerated seven-day maintain timeline...` 通过移动专用测试数据库的持久业务时间戳压缩一周时间：等待人工 → 修复 → 达标 → 注入退化 → 重新修复 → 遥测缺失 → 恢复采样 → 到期。租约和模型调用仍使用当前真实时间。覆盖率测试断言 totalMs 恰好 7 天，并同时保留 healthy、unhealthy、missing 区间。

**这不是连续运行一周的实测。** 本次已完成分钟级真实运行、故障注入和进程硬重启验证；日/周级持续运行需要后续真实时间观察。主机休眠、PostgreSQL 离线、第三方 SDK 长期行为和真实外部系统副作用不因加速测试通过而视为已证明。
